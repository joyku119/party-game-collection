# 今晚玩什麼？Party Game Collection

一個專為朋友聚會、多人派對與酒局設計的**可擴充式互動小遊戲資料庫**，收錄 **50 款**經典與熱門派對遊戲，並透過 `AGENTS.md` 建立標準化的內容與開發規範，讓 AI 能持續依循相同架構擴充新遊戲與功能。

## 專案特色

- **50 款精選聚會小遊戲**：涵蓋反應力挑戰（9 款）、記憶力挑戰（8 款）、心理戰與猜測（9 款）、口才與表達（8 款）、默契與互動（8 款）、卡牌與骰子（8 款）六大分類。
- **依人數自動跳出遊戲推薦**：頁面頂部提供聚會人數選擇器（2 人、4 人、6 人、8 人、10 人以上或自由微調），選取人數後即時跳出最適合的遊戲推薦。
- **「不知道玩什麼？」隨機抽遊戲**：隨機抽出一款遊戲，顯示遊戲名稱、人數、時間、所需道具與「第一步開始方式」。
- **分類篩選、搜尋與個人收藏**：支援六大分類篩選、人數過濾、關鍵字搜尋與 `localStorage` 遊戲收藏清單。
- **內建派對倒數計時器**：提供 5 秒 / 15 秒 / 30 秒 / 60 秒 / 3 分鐘預設，支援限時挑戰類遊戲。
- **AI 可持續擴充規範**：完整定義於 [`AGENTS.md`](./AGENTS.md)。

## 本地預覽與 GitHub Pages 部署

### 本地預覽
直接雙擊開啟 `index.html`，或在專案目錄下執行：

```bash
python3 -m http.server 8080
```

### 部署至 GitHub Pages
1. 在 GitHub 建立新的公開 Repository（例如 `party-game-collection`）。
2. 將本資料夾內的所有檔案上傳推送至 `main` 分支。
3. 前往 **Settings → Pages**，將 Source 設為 `Deploy from a branch`，Branch 選擇 `main` / `/ (root)` 後儲存即可瀏覽。
